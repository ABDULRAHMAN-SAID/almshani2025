# Third Person Prototype — Godot 4

نموذج أولي لعبة **أكشن/مغامرة بمنظور الشخص الثالث** ثلاثية الأبعاد، على محرك **Godot 4** (عارض Forward+، وهو الأنسب لأعلى جودة رسومية يقدمها Godot).

> ملاحظة: هذا مشروع منفصل تماماً عن فرع `claude/unity-6-setup-16j376` (مشروع Dawnkeep على Unity) الموجود في نفس المستودع. لا علاقة بينهما.

## المتطلبات

- **Godot 4.2 أو أحدث** (نسخة Standard تكفي؛ نسخة .NET غير مطلوبة، المشروع بالكامل GDScript).

## التشغيل

1. افتح **Godot Engine** → **Import** → اختر ملف `project.godot` في جذر هذا المستودع.
2. اضغط **F5** أو زر التشغيل (▶). المشهد الرئيسي `scenes/main.tscn` سيُشغَّل تلقائياً.

## عناصر التحكم

| المفتاح | الفعل |
|---|---|
| `W` `A` `S` `D` | الحركة (نسبة إلى اتجاه الكاميرا) |
| `Shift` | الجري |
| `Space` | القفز |
| حركة الفأرة | تدوير الكاميرا حول الشخصية |
| `Esc` | تحرير/إعادة أسر مؤشر الفأرة |

## ما هو موجود الآن

- تحكم شخصية ثلاثي الأبعاد (`CharacterBody3D`) بمنظور الشخص الثالث: مشي، جري، قفز، كاميرا مدارية بذراع نابض (`SpringArm3D`) لا تخترق الجدران.
- ساحة اختبار صغيرة: أرضية + 3 عوائق، إضاءة شمس مع ظلال، سماء إجرائية، وإعدادات بيئة (Glow، SSAO، SSIL، ACES tonemap) لرفع الجودة البصرية دون الحاجة لأصول فنية جاهزة.
- ربط مفاتيح الحركة يتم برمجياً عبر `scripts/input_setup.gd` (autoload) بدل كتابته يدوياً داخل `project.godot`، لتفادي أخطاء رموز المفاتيح.

هذا **بداية قابلة للّعب فعلياً**، وليس تصميماً نهائياً — لا يوجد بعد: قصة، أعداء، نظام قتال، أو أصول فنية نهائية. الخطوة التالية تُبنى حسب ما تحدده لاحقاً (نوع القتال، عالم اللعبة، الفن المطلوب...).

## بنية المجلدات

```
project.godot       إعدادات المشروع
icon.svg             أيقونة مؤقتة
scenes/main.tscn     المشهد الرئيسي (الساحة + الإضاءة + اللاعب)
scenes/player/       مشهد اللاعب
scripts/             GDScript (اللاعب + إعداد المفاتيح)
assets/              الأصول الفنية (فارغ حالياً — نماذج/قوام/صوت لاحقاً)
```
