# Ember Vale (اسم مؤقت) — Godot 4

نموذج أولي لعبة **أكشن/مغامرة فانتازيا** (سيوف/سحر/وحوش) بمنظور الشخص الثالث، **موجّهة للجوال أولاً** (أندرويد/iOS)، على محرك **Godot 4** بعارض **Mobile** (الأنسب لأداء حقيقي على الهواتف). الاسم مؤقت بحت — غيّره متى حددت اسم اللعبة الفعلي.

> ملاحظة: هذا مشروع منفصل تماماً عن فرع `claude/unity-6-setup-16j376` (مشروع Dawnkeep على Unity) الموجود في نفس المستودع. لا علاقة بينهما.

## المتطلبات

- **Godot 4.2 أو أحدث** (نسخة Standard تكفي؛ نسخة .NET غير مطلوبة، المشروع بالكامل GDScript).

## التشغيل (على جهازك، بعد سحب الفرع)

1. افتح **Godot Engine** → **Import** → اختر ملف `project.godot` في جذر هذا المستودع.
2. اضغط **F5** أو زر التشغيل (▶). المشهد الرئيسي `scenes/main.tscn` سيُشغَّل تلقائياً.

اللعبة تعمل بعناصر تحكم لمسية على الشاشة حتى أثناء التجربة على جهاز الكمبيوتر — لا حاجة لهاتف فعلي للتجربة الأولى.

## عناصر التحكم

| العنصر | الفعل |
|---|---|
| العصا التحكمية (أسفل يسار الشاشة) | الحركة — الميل الكامل يعطي جرياً، الميل الجزئي مشياً |
| السحب في أي مكان آخر من الشاشة | تدوير الكاميرا حول الشخصية |
| زر «قفز» (أسفل يمين) | القفز |
| زر «قدرة» (أسفل يمين) | إطلاق كرة نارية سحرية باتجاه نظر الكاميرا |
| لوحة المفاتيح (اختياري، للاختبار على الكمبيوتر) | `WASD` حركة، `Space` قفز، `E` قدرة، السحب بالفأرة (زر يسار) لتدوير الكاميرا |

## ما هو موجود الآن

- تحكم شخصية ثلاثي الأبعاد (`CharacterBody3D`) بمنظور الشخص الثالث مصمم للمس: عصا تحكمية تلمسية للحركة، سحب حر للكاميرا (`SpringArm3D`)، وزرّا قفز/قدرة — كلها مبنية على نفس نظام Input action فلا فرق بالكود بين لمس وفأرة ولوحة مفاتيح.
- **أول قدرة سحرية فعلية**: كرة نارية (`scenes/fire_bolt.tscn`) تُطلق باتجاه نظر الكاميرا، تصطدم بأي جسم له `take_damage()`، وتختفي عند الاصطدام أو بعد 3 ثوانٍ.
- **دمية تدريب** (`TrainingDummy`) تومض وتتقلّص لحظياً عند إصابتها وتختفي عند نفاد صحتها — أول حلقة قتال كاملة وإن كانت مبسّطة (لا يوجد بعد أعداء متحركون أو شريط صحة).
- ساحة اختبار صغيرة: أرضية + 3 عوائق، إضاءة شمس مع ظلال، سماء إجرائية، وGlow لرفع الجودة البصرية دون الحاجة لأصول فنية جاهزة.
- عارض **Forward+** مع أقصى إعدادات جودة يقدمها Godot 4 حالياً: SSAO، SSIL، SDFGI (إضاءة عامة واقعية بالزمن الفعلي)، Glow، وACES tonemap. هذا لتقييم السقف البصري الأعلى أثناء التطوير على الكمبيوتر — **لن يعمل بنفس الأداء على هاتف فعلي**؛ قبل أي تصدير حقيقي للجوال سنرجع لعارض Mobile (أخف بكثير) ونحذف SSAO/SSIL/SDFGI لأنها حصرية على Forward+.

هذا **بداية قابلة للّعب فعلياً**، وليس تصميماً نهائياً — لا يوجد بعد: قصة، أعداء يتحركون، تنويع قدرات، أو أصول فنية نهائية (كل الأشكال حالياً كبسولات وصناديق بسيطة). الخطوة التالية تُبنى حسب ما تحدده لاحقاً.

## بنية المجلدات

```
project.godot        إعدادات المشروع (عارض Mobile، اتجاه أفقي)
icon.svg              أيقونة مؤقتة
scenes/main.tscn      المشهد الرئيسي (الساحة + الإضاءة + اللاعب + الدمية + الواجهة)
scenes/player/        مشهد اللاعب
scenes/fire_bolt.tscn مشهد القدرة السحرية (كرة نارية)
scripts/              GDScript: اللاعب، القدرة، الدمية، العصا التحكمية، الأزرار، إعداد المفاتيح
assets/               الأصول الفنية (فارغ حالياً — نماذج/قوام/صوت لاحقاً)
```
