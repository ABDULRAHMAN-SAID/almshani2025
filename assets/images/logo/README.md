# شعار سلاح الجو السلطاني العماني

استبدل `logo.png` بصورة الشعار الرسمي (يُفضّل PNG بخلفية شفافة، مربع الأبعاد، 512×512 بكسل على الأقل).

بعد الاستبدال، الشعار يظهر تلقائيًا في:
- شاشة البداية (Splash)
- شاشة تسجيل الدخول
- رأس الصفحة الرئيسية
- أيقونة التطبيق (`app.json`)

لا حاجة لتعديل أي كود — المكوّن `src/components/Logo.tsx` وملف `app.json` يشيران إلى هذا المسار مباشرة.
