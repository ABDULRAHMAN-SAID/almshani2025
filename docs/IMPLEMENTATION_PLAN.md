# خطة التنفيذ — مملكة الرماد

الحالة الحالية: **بدأ نقل المشروع إلى Unity 6 بـ 3D URP**. النموذج المتصفّحي (`docs/prototype/dawnkeep-3d.html`) يبقى **مرجع التصميم والتوازن وحلقة اللعب**، ونسخة Unity هي المنتج النهائي.

> **تحويل موثّق**: المشروع انتقل من 2D URP / Orthographic إلى **3D URP / Perspective** — انظر §46 في المواصفات و`docs/UNITY_3D_SETUP.md`.

## البنية

```
dk3d.core.html          ← النواة (توليدها من dk3d.base5.html عبر patch_p1/p15/p16)
m_weapons.js  m_units.js  m_ui.js  m_meta.js   ← وحدات تُدرَج عند /*@@MODULES@@*/
assemble.py → dawnkeep3d.html (المنشور)  ·  mktests.py → t3d.html / t3dfast.html / game3d.js
```

النواة لا تعرف الوحدات إلا عبر نقاط تمديد (`heroCombat`, `weaponActive`, `unitStats`, `soldierBehavior`, `renderOrders`, `openPause`, `openLoadout`) وخطّافات (`HOOKS.kill/dawn/nightStart/tick/draw/hurt/longPress/build`) وجداول بيانات (`WEAPONS/PERKS/MUTATORS/UNITS`) و`MOD` للمعدِّلات. انظر `MODULES.md` في مجلد العمل.

## المراحل القادمة (بالترتيب)

1. **Unity 6 — البناء والاقتصاد** (§10): `BuildingDefinition` وعقد البناء ووضع المباني ومواردها. الحلقة اليوم قتال بلا اقتصاد.
2. **Unity 6 — أوامر الفرق** (§7 و§9): اختيار الفرق وأمرها بالتقدّم والتراجع والمرابطة. `Unit` يحمل اليوم موضع مرابطة، وينقصه من يأمره.
3. **Localization**: مفاتيح بدل النصوص الثابتة في الكود. `ArabicShaper` جاهز لاستقبال أي نصّ منطقي، فالنقل يمسّ مصدر النصّ لا رسمه.
2. باليستا وبرج دعم، ميدان رماة مستقل، مقر أبطال (4 وحدات خاصة).
3. حدادة/أبحاث (4–6 لكل خريطة) وMeta progression كامل (XP، فتح الأسلحة 4–8، البركات حتى 20).
4. خرائط 4–8 مع اقتصاد مختلف لكل بيئة، وأهداف خاصة، ثم «الحملة الأبدية».
5. صوت حقيقي بدل النغمات المولّدة، ولوحة نتائج شبكية عند وجود خادم.
