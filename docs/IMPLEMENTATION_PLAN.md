# خطة التنفيذ — مملكة الرماد

الحالة الحالية: **النموذج ثلاثي الأبعاد في المتصفح** (`docs/prototype/dawnkeep-3d.html`) هو مرجع التصميم والتوازن قبل بناء نسخة Unity 6. كل مرحلة أدناه مُنفَّذة واختُبرت آلياً ما لم يُذكر خلاف ذلك.

## المراحل المنجزة

| المرحلة | المحتوى | التحقق |
|---|---|---|
| 0 | نموذج 2D: الحلقة الأساسية، اقتصاد، جنود، بركات | حملة آلية |
| 1 | نموذج 3D: ثلاث مراحل، ثلاثة زعماء، أسوار، ستة مبانٍ، نور | حملة آلية كاملة |
| 2 | إعادة بناء بصرية: تضاريس، PBR، هياكل بمفاصل، مبانٍ مفصّلة | لقطات |
| 3 | طبقة المراجعة التصميمية الأولى: كاميرا، عقد حقيقية، معاينة، صور، ذهب، HUD | لقطات + حملة |
| 4 | هاتف أولاً + تفاصيل | جهاز 844×390 محاكى |
| 5 | عالم ×5: سماء، جبال، بحيرة، غابات، طرق، أجساد مستديرة، حلقة سور كاملة | لقطات + ليلة زعيم |
| 6 | مراجعة متعددة العيون: 30 إصلاحاً، أداء ×5، لمس، صقل | ليلتا زعيم A/B |
| 7 | **الوثيقة الرئيسية — المرحلة 1**: طبقة بيانات (خرائط/مبانٍ/أعداء/موجات)، آلة حالات، عقد مصنّفة، قفل تعليمي، مستويات القلعة، انتقال الليل، معاينة الموجة، تقرير الفجر، أولويات الأعداء، زعيم بمراحل، حواجز، نتيجة | تدفق آلي (اختيار العقد، القفل، الترقية، ليلة كاملة، التقرير) |
| 8 | **الوحدات**: `m_weapons` (3 أسلحة + 6 بركات + 3 معدِّلات)، `m_units` (4 وحدات + أوامر + مجموعتان)، `m_ui` (تجهيز، إيقاف بتبويبات، إعدادات، صوت مقنّن، تكبير)، `m_meta` (قفل هدف، هزيمة، حفظ، خريطة الحملة، مهام) | اختبار لكل وحدة + مراجع مستقل |

## البنية

```
dk3d.core.html          ← النواة (توليدها من dk3d.base5.html عبر patch_p1/p15/p16)
m_weapons.js  m_units.js  m_ui.js  m_meta.js   ← وحدات تُدرَج عند /*@@MODULES@@*/
assemble.py → dawnkeep3d.html (المنشور)  ·  mktests.py → t3d.html / t3dfast.html / game3d.js
```

النواة لا تعرف الوحدات إلا عبر نقاط تمديد (`heroCombat`, `weaponActive`, `unitStats`, `soldierBehavior`, `renderOrders`, `openPause`, `openLoadout`) وخطّافات (`HOOKS.kill/dawn/nightStart/tick/draw/hurt/longPress/build`) وجداول بيانات (`WEAPONS/PERKS/MUTATORS/UNITS`) و`MOD` للمعدِّلات. انظر `MODULES.md` في مجلد العمل.

## المراحل القادمة (بالترتيب)

1. **Unity 6 (2D URP، Isometric)**: نقل طبقة البيانات إلى ScriptableObjects بنفس الأسماء (`BuildingDefinition`, `EnemyDefinition`, `WaveDefinition`, `WeaponDefinition`, `PerkDefinition`, `MutatorDefinition`, `MapDefinition`, `UnitDefinition`)، وآلة الحالات كـ `GamePhase` منفصلة، وObject Pooling، وSpatial Hash للاستهداف.
2. باليستا وبرج دعم، ميدان رماة مستقل، مقر أبطال (4 وحدات خاصة).
3. حدادة/أبحاث (4–6 لكل خريطة) وMeta progression كامل (XP، فتح الأسلحة 4–8، البركات حتى 20).
4. خرائط 4–8 مع اقتصاد مختلف لكل بيئة، وأهداف خاصة، ثم «الحملة الأبدية».
5. صوت حقيقي بدل النغمات المولّدة، ولوحة نتائج شبكية عند وجود خادم.
