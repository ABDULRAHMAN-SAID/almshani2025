# خطة التنفيذ — مملكة الرماد

الحالة الحالية: **بدأ نقل المشروع إلى Unity 6 بـ 3D URP**. النموذج المتصفّحي (`docs/prototype/dawnkeep-3d.html`) يبقى **مرجع التصميم والتوازن وحلقة اللعب**، ونسخة Unity هي المنتج النهائي.

> **تحويل موثّق**: المشروع انتقل من 2D URP / Orthographic إلى **3D URP / Perspective** — انظر §46 في المواصفات و`docs/UNITY_3D_SETUP.md`.

## المراحل القادمة (بالترتيب)

1. **ضبط توازن §10** (المقابض جاهزة): `BalanceSettings` ثلاثة أرقام يقرؤها الباني والفحص معاً، والافتراضي أرقام §10 كما هي. القياس: عدد العقد وحده يبلغ الهدف (٦ عقد ← ١٤)، والمضاعف لا يبلغه حتى ٤×، وعدد الموجات لا أثر له. الاختيار لصاحب المشروع من المفتِّش.
2. **الخريطة المصغّرة** (§7): زرٌّ أعلى الشاشة يفتح خريطةً تُظهر المواقع والمهاجمين. اليوم مكانه زرُّ تثبيت الكاميرا على الحصن (§6) — وزرٌّ يفتح ما لا وجود له ممنوع (§17).
3. **عصا §7 الافتراضية**: العصا العائمة على اليسار للجوّال. الإدخال اليوم بالمفاتيح ويد التحكّم، والقدرات تشغل اليسار مؤقّتاً حتى تُبنى.
2. باليستا وبرج دعم، ميدان رماة مستقل، مقر أبطال (4 وحدات خاصة).
3. حدادة/أبحاث (4–6 لكل خريطة) وMeta progression كامل (XP، فتح الأسلحة 4–8، البركات حتى 20).
4. خرائط 4–8 مع اقتصاد مختلف لكل بيئة، وأهداف خاصة، ثم «الحملة الأبدية».
5. صوت حقيقي بدل النغمات المولّدة، ولوحة نتائج شبكية عند وجود خادم.
